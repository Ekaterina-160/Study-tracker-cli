# Study Tracker

Учебное Flask-приложение для учёта школьных оценок. Пользователь может зарегистрироваться, войти в аккаунт и добавить запись об оценке через защищённый маршрут.

## Возможности

- регистрация пользователя;
- вход пользователя через Flask-Login;
- защита страницы добавления оценки от гостей;
- сохранение пользователей и оценок в SQLite через SQLAlchemy;
- форма добавления оценки с CSRF-защитой через Flask-WTF.

## Требования

- Python 3.10 или новее;
- зависимости из `requirements.txt`.

## Установка

Создайте и активируйте виртуальное окружение, затем установите зависимости:

```bash
pip install -r requirements.txt
```

Создайте файл `.env` в корне проекта:

```env
SECRET_KEY=your-secret-key
SQLALCHEMY_DATABASE_URI=sqlite:///journal.db
SQLALCHEMY_TRACK_MODIFICATIONS=False
```

## Запуск

Из корня проекта:

```bash
python app.py
```

После запуска приложение будет доступно по адресу:

```text
http://127.0.0.1:5000
```

## Основные маршруты

- `/` — главная страница;
- `/health` — проверка, что приложение работает;
- `/register` — регистрация нового пользователя;
- `/login` — вход пользователя;
- `/add_grade` — добавление оценки, доступно только после входа.

## Модели данных

`User` хранит пользователей приложения. Пароль сохраняется не в открытом виде, а как хеш в поле `password_hash`.

`GradeRecord` хранит запись об оценке: имя ученика, предмет, балл, дату, тип работы и комментарий.

`StudySession` заготовлена для будущего учёта учебных сессий.

## Авторизация

Маршрут `/add_grade` защищён декоратором `@login_required`. Если неавторизованный пользователь попробует открыть эту страницу, Flask-Login перенаправит его на `/login`.
