# Study Tracker CLI

Консольное приложение на Python для учёта школьных оценок: добавление записей, просмотр по предмету и ученику, расчёт средних баллов. Данные хранятся в файле `grades.json`.

## Требования

- Python 3.10 или новее
- Только стандартная библиотека (внешние зависимости не нужны)

## Запуск

Из корня проекта:

```bash
py study.py
```

или:

```bash
python study.py
```

## Меню

| Пункт | Действие |
|-------|----------|
| 1 | Добавить запись об оценке |
| 2 | Показать все оценки по предмету |
| 3 | Показать все записи |
| 4 | Общий средний балл по всем записям |
| 5 | Средний балл по каждому предмету |
| 6 | Средний балл ученика по всем предметам |
| 7 | Все записи конкретного ученика |
| 0 | Выход |

При неверном вводе в меню или при вводе числовых полей (класс, оценка) программа не завершается — выводится сообщение об ошибке и запрос повторяется.

## Структура проекта

```
Study-tracker-cli/
├── study.py       # Точка входа, интерактивное меню
├── models.py      # Модели данных, репозитории, аналитика
├── grades.json    # Хранилище оценок (создаётся автоматически)
└── README.md
```

### models.py

- **GradeRecord** — одна оценка (класс, ученик, предмет, балл, дата, тип, комментарий).
- **GradeRepository** — чтение и запись оценок в `grades.json`.
- **GradeAnalytics** — расчёт средних баллов.
- **StudySession**, **SessionRepository**, **SessionAnalytics** — заготовки для учёта сессий подготовки (пока не подключены к меню).

### Формат записи в grades.json

```json
{
  "id": 1,
  "class_number": 10,
  "student_name": "Иванов Иван",
  "subject": "Математика",
  "grade": 5.0,
  "recorded_at": "2026-06-08T10:00:00",
  "assessment_type": "контрольная",
  "comment": ""
}
```

Поле `class_number` — целое число. При загрузке строковые значения из старых файлов приводятся к `int`.

## Поведение при ошибках

- Несуществующий ученик при расчёте среднего (пункт 6) — сообщение «Ученик не найден или нет записей», без падения программы.
- Пустой список оценок при общем среднем (пункт 4) — сообщение «Нет записей для расчёта».
- Поиск по предмету и ученику не зависит от регистра букв.
